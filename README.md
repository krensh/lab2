# ✦ stargazing ideas

Интерактивный одностраничный сайт-загадка, посвященный поиску вдохновения. 

## 🌌 О проекте
Проект представляет собой иммерсивный опыт, где пользователь взаимодействует со звездами на черном фоне. Сайт состоит из нескольких этапов-экранов, которые открываются по мере решения логических задач.

## 🛠 Стек технологий
*   **HTML5** — семантическая разметка.
*   **CSS3** — стилизация, адаптивная типографика (`clamp`), кастомные анимации свечения (`drop-shadow`), SVG-градиенты.
*   **Vanilla JavaScript** — вся логика взаимодействия, отслеживание состояния звезд, Drag-and-Drop для каруселей и блокировка скролла.
*   **GitHub Pages** — хостинг (с подключенным кастомным доменом).
